# Photos

Fiche documentaire pour l application Photos de Windows.

Documentation sheet for the Windows Photos app.

## Sources

- https://support.microsoft.com/en-us/help/13805

## Notes de recherche

- Version / plateforme: application Photos de Windows 10/11.
- Couverture: la source Microsoft "Keyboard shortcuts in apps" documente les raccourcis communs des applications Windows, dont les commandes photo de base. Les raccourcis specifiques a l application Photos moderne restent peu exposes publiquement.
- Raccourcis Fn / touches F: `F5` peut demander `Fn` selon le clavier.
- Raccourcis exclus: raccourcis generiques d app sans comportement Photo verifie, et commandes d edition trop dependantes du mode ouvert.
- Risques: aucun raccourci destructif direct retenu; `Ctrl` + `S` peut ecraser des modifications selon le flux de l application.
