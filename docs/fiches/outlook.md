# Outlook

Fiche documentaire pour les raccourcis Outlook utiles sur Windows.

Documentation sheet for useful Outlook shortcuts on Windows.

## Sources

- https://support.microsoft.com/en-us/office/keyboard-shortcuts-for-outlook-3cdeb221-7ae5-4c1d-8c1d-9e63216c1efd

## Notes de recherche

- Version / plateforme: Outlook desktop Windows pour Microsoft 365, Office 2024, Office 2021, Office 2019 et Office 2016 quand le raccourci est couvert par la documentation Microsoft; nouveau Outlook pour Windows quand la source le signale.
- Badges proposes: 365, 2024, 2021.
- Couverture: selection centree sur courrier, navigation et calendrier. Certains raccourcis peuvent varier si Outlook utilise le mode de raccourcis Outlook, Gmail ou Yahoo.
- Raccourcis Fn / touches F: `F9` peut demander `Fn` selon le clavier.
- Raccourcis exclus: raccourcis propres au web, dossiers publics, notes, journal et commandes de calendrier tres specialisees.
- Risques: `Alt` + `S` envoie le message; `Ctrl` + `D` supprime l element selectionne.
