# Thunderbird

Fiche documentaire pour les raccourcis Thunderbird utiles sur Windows.

Documentation sheet for useful Thunderbird shortcuts on Windows.

## Sources

- https://support.mozilla.org/en-US/kb/keyboard-shortcuts-thunderbird

## Notes de recherche

- Version / plateforme: Thunderbird desktop, Windows 11 cible; la page Mozilla indique aussi les variantes macOS/Linux.
- Couverture: inventaire base sur la documentation officielle Thunderbird, qui precise que les raccourcis sont sensibles au contexte actif.
- Raccourcis Fn / touches F: `F1`, `F2`, `F5`, `F6`, `F7`, `F8` et `F9` peuvent demander `Fn` selon le clavier.
- Raccourcis clavier/souris: selection multiple, zoom molette et deplacement/copie par glisser sont documentes; seuls les plus utiles sont proposes et demandent un rendu clic/molette/glisser avant JSON.
- Raccourcis exclus: raccourcis macOS seuls, newsgroups rares, calendrier, carnet d adresses avance, reordonnancement fin de pieces jointes.
- Risques: `Shift` + `Delete` supprime sans corbeille; `Ctrl` + `Enter` envoie un message immediatement.

## Langue logiciel / clavier

- Statut audit 2026-06-01: fiche conservee comme selection existante; aucune correction de touche localisee n'est promue sans source localisee ou validation explicite.
- Les sections Francais et English restent separees: ne pas deduire une touche FR depuis une source EN traduite.
- Les touches de ponctuation, les actions souris et les sequences `Alt` doivent etre reverifiees par langue de logiciel et disposition AZERTY/QWERTY avant ajout de `keysByLayout`.
